# 📚 Моя библиотека

**Простое приложение на Python для управления личной коллекцией книг.**

![Python](https://img.shields.io/badge/Python-3.12-3776AB?logo=python&logoColor=white)
![Flask](https://img.shields.io/badge/Flask-3.x-000000?logo=flask&logoColor=white)
![Interface](https://img.shields.io/badge/Interface-Web%20%26%20CLI-315BD4)

## Возможности

| Функция | Описание |
| --- | --- |
| 📖 Каталог | Просмотр книг в удобной таблице |
| ➕ Добавление | Название, автор и год издания |
| 🔍 Поиск | По названию, автору или году |
| 🔄 Статусы | «В наличии» и «Выдана» |
| 🗑️ Удаление | С подтверждением в веб-интерфейсе |
| 📊 Статистика | Всего книг, в наличии и выдано |

Веб-интерфейс работает в браузере и не требует установки отдельного графического приложения. Данные сохраняются в текстовом файле.

## Быстрый старт

### GitHub Codespaces

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/Denis-create-boop/library?quickstart=1)

Откройте Codespaces, затем выполните в терминале:

```bash
pip install -r requirements.txt
python app.py
```

Когда Codespaces предложит открыть порт **5000**, нажмите **Open in Browser**. Для личной работы оставьте порт приватным.

### Локальный запуск

Требуется Python 3.12.

```bash
git clone https://github.com/Denis-create-boop/library.git
cd library
python -m pip install -r requirements.txt
python app.py
```

Откройте [http://localhost:5000](http://localhost:5000) в браузере.

### Консольная версия

Исходное консольное приложение также сохранено:

```bash
python main.py
```

## Структура проекта


## Технологии

- **Python** — логика приложения.
- **Flask** — веб-сервер и обработка запросов.
- **Jinja2, HTML, CSS и JavaScript** — интерфейс.
- **Текстовый файл** — хранение данных без отдельной СУБД.

## Хранение данных

Веб-версия поддерживает чтение UTF-8 и Windows-1251 и сохраняет изменения в существующем формате `library.txt`. Перед экспериментами рекомендуется сделать резервную копию файла. Не запускайте обе версии одновременно для изменения одного каталога: консольная версия использует отдельную логику работы с данными и может требовать адаптации кодировки.

Приложение предназначено для личного и учебного использования. Встроенной авторизации нет; не публикуйте веб-сервер в открытый доступ.
